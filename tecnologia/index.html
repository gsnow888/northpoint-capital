Preguntas

¿Otra duda? Agenda una sesión
01¿Qué es la tecnología NORTHPOINT?+

Un conjunto de cinco herramientas para traders: Academia y KURO para aprender, Alpha Agents y DEPTH para leer el mercado, y el Terminal para operar y registrar. Cada una funciona por separado.

02¿Necesito experiencia para empezar?+

No. Si apenas empiezas, la Academia y KURO te dan bases y práctica. Las herramientas de análisis y el Terminal están pensadas para quien ya opera.

03¿En qué equipos funcionan?+

El Terminal y DEPTH tienen app para Mac y Windows, y DEPTH también corre en el navegador. Las demás funcionan en la web.

04¿Dan señales o recomendaciones de inversión?+

No. Son herramientas de análisis, práctica y registro. Muestran datos; la decisión de operar siempre es tuya.

05¿Cuánto cuesta?+

Cada herramienta tiene su propio plan. Encuentra el precio en la página de cada una.
